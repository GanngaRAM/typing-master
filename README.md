# TypeRush

A simple browser-based typing game focused on speed, accuracy, and consistency.

Words move across the screen and you have to type them before they disappear. Your WPM, accuracy, score, and streak are tracked while you play.

## Features

* Moving words with increasing speed
* WPM and accuracy tracking
* Score and streak system
* Restart button
* Responsive layout
* No frameworks or dependencies

## Tech Stack

* HTML
* CSS
* JavaScript

Built as a small project to practice frontend development and JavaScript game logic.
